# Penny Pal 🐷

A free, friendly budget app made for Ontario. Open it here: https://jparma-ghub.github.io/penny-pal/

Everything you type stays in your own browser on your own computer. Nothing is sent anywhere.

Want your own copy that works offline? Download `penny-pal.zip`, unzip it and double click `index.html`. See `GUIDE.md` for how to change things.
